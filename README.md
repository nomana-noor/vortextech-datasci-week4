# VortexTech Week 4 - End-to-End Analysis Report 

## What I Built
A complete, business-focused analysis report on the Amazon Sales Dataset, examining what separates highly-rated products from poorly-rated ones. The report includes an executive summary, 4 key findings backed by 5 polished visualizations, and 3 actionable business recommendations.

## Key Findings
1. Electronics is the most popular category but has the lowest average rating
2. Lower discounts don't mean lower ratings — Office Products proves this with high ratings and minimal discounting
3. Higher-priced products tend to receive slightly better ratings
4. Poorly-rated products are discounted more heavily yet receive far fewer reviews than top-rated products

## How to Run
1. Install required libraries: `pip install pandas matplotlib seaborn jupyter`
2. Open `vortextech_week4.ipynb` in Jupyter Notebook
3. Run all cells to see the full report, including the executive summary, findings, and recommendations
